# Интеграция FoxholeHQ

## Фактический источник

Исследовано 13 августа 2026 года:

- страница: `https://foxholehq.com/calculator`;
- bundle: `https://foxholehq.com/static/calculator.js`;
- публичный REST endpoint каталога не найден;
- сетевые запросы страницы не загружают отдельный JSON каталога;
- структурированный dataset находится в JavaScript-объекте `const iteminfo={...}`;
- категория и фракция находятся в `data-item` и классах кнопок страницы;
- страница указывает версию `Patch 61`, последнее обновление `6/18/25`.

На момент проверки dataset содержит 185 предметов. Запись `iteminfo` содержит:

```text
name, type, desc, ammo, produces, bmat, rmat, emat, hemat
```

FoxholeHQ обфусцирует строки через локальную таблицу и индексную функцию.
`FoxholeHQDataProvider` разбирает только литералы ожидаемого объекта через
`ast.literal_eval`; upstream JavaScript не выполняется. HTML используется только
для метаданных dataset и ссылки на bundle, а не для извлечения цен.

## Нормализация

Провайдер преобразует данные в предметы и рецепты с методами `factory`, `garage`
и `mpf`. Для техники цена ящика из трёх машин разделяется на цену одной машины в
Garage, а исходная цена ящика остаётся базой MPF. MPF-скидку считает бот:
`0%, 10%, 20%, 30%, 40%, 50%`, далее 50%.

Поскольку стабильного ID FoxholeHQ нет, используется нормализованный upstream-key.
Rename дополнительно определяется по fingerprint типа, описания, боеприпаса и
размера ящика. Неоднозначный rename автоматически не объединяется.

## Защита данных

До записи в PostgreSQL проверяются количество предметов, рецептов, техники,
оружия и доля пустых рецептов. При ошибке текущий каталог не очищается. Dataset с
тем же SHA-256 повторно не применяется. Исчезнувшие предметы получают
`is_active=false`; русские локализации, алиасы и overrides не меняются.

Тикет-система не вызывает FoxholeHQ. Она читает локальный каталог, а каждая
позиция заказа получает неизменяемый snapshot цен и версии данных.
